# 바로미 운영 준비 체크리스트

이 문서는 합성 데모 통과와 실제 서비스 출시를 구분한다. 체크된 항목도 배포 환경에서 다시 확인해야 한다.

## 코드로 검증된 항목

- [x] 공개 HTTPS URL 검증과 사설·예약 IP 차단
- [x] 공개 HTML 일시 연결 오류의 제한적 재시도와 영구 실패 구분
- [x] URL 초기 HTML 정적 진단과 부분 완료 보고서
- [x] 소유 확인 후 동적 구매 흐름 전환
- [x] 메타 태그·`.well-known` 파일·DNS TXT 소유 확인
- [x] 테스트 계정 암호화 보관·작업 종료·대기 취소 후 삭제
- [x] 실제 주문 확정·결제 없이 주문서 직전에서 중단
- [x] 화면·API 가격 근거와 증거 스크린샷 저장
- [x] 개인정보 입력 필드 마스킹
- [x] 진단 중복 요청 방지·취소·소유자 삭제
- [x] 상점별 진단 이력과 JSON 보고서 다운로드
- [x] 보관 기간 정리 작업과 DB·워커 큐 헬스체크
- [x] 요청 본문·API 남용 제한·보안 응답 헤더
- [x] 수집 실패 유형 코드화(`FETCH_FAILED`, `PRODUCT_NOT_FOUND`, `DYNAMIC_RENDER_FAILED`, `DYNAMIC_JOURNEY_FAILED`)
- [x] 데이터베이스·증거 디렉터리 동시 백업·복구 명령
- [x] 합성 평가 40건 및 문구 변형·정상 대조군 16건 반복 평가

## 실제 배포 전에 필요한 외부 검증

- [ ] 소유권을 받은 카페24 테스트몰에서 PC·모바일·장바구니·바로구매 도달률 측정
- [ ] 로그인·회원가·배송지·조건부 배송비가 있는 승인 테스트몰 검증
- [ ] 동일 상점 반복 실행 일치율과 탐색 실패 유형 기록
- [x] SQLite 백업·복구 리허설(임시 별도 경로, `PRAGMA integrity_check=ok`, 증거 712개 복원)
- [ ] 워커 단일 실행·재시작·6분 초과 작업 회복 시험
- [ ] 고객 인증 체계(계정/OAuth 또는 조직 초대)와 세션 폐기 정책 결정
- [ ] AI 보조 판정 사용 시 데이터 최소화·비용 상한·모델/프롬프트 버전 기록 검증
- [ ] 개인정보 처리방침·보관 기간·삭제 요청 절차를 배포 환경에 반영

## 출시 판단 원칙

합성 평가의 정밀도·재현율은 실제 쇼핑몰 성능의 보증이 아니다. 위 외부 검증 중 탐색 도달률, 반복 일치율, 데이터 삭제·복구 시험을 통과하기 전에는 결과를 “적법/위법” 또는 “검사 통과”로 표현하지 않는다.
