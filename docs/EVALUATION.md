# P0 탐지 평가

> 아래 수치는 합성·문구 평가셋의 재현성 측정이다. 실제 고객 쇼핑몰의 탐지 정확도나 법적 판단을 보증하지 않는다.

Playwright로 한국어 합성 구매 흐름 40건을 탐색했다. 사전선택 20건과 순차공개 가격책정 20건에 대해 각각 위험 사례 10건과 정상 사례 10건을 준비했다. 40건 전체에서 규칙별로 해당 유형 발견 여부를 집계했고, 사례의 정확 일치는 예상 유형·단계·발견 건수가 모두 일치할 때로 정의했다.

## 로컬 측정 결과

최신 기준 실행은 `npm run evaluate`와 `npm run evaluate -- --text-validation`으로 재현한다. 기본 구매 흐름 40건은 정확 일치 40/40, 단계 도달 120/120, 반복 일치 40/40, 평균 약 530ms였다. 확장 문구·정상 대조군 29건은 정확 일치 29/29, 단계 도달 87/87, 반복 일치 29/29, 16개 규칙별 정밀도·재현율 100%, 평균 약 539ms였다. 이 결과는 규칙 회귀 검증용이며 실제 쇼핑몰 검증과 분리한다.

| 규칙 | 버전 | TP | FP | FN | TN | 정밀도 | 재현율 | F1 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 사전선택 | 1 | 5 | 0 | 5 | 30 | 100% | 50% | 66.7% |
| 사전선택 | 2 | 8 | 0 | 2 | 30 | 100% | 80% | 88.9% |
| 사전선택 | 3 | 10 | 0 | 0 | 30 | 100% | 100% | 100% |
| 순차공개 가격책정 | 1 | 6 | 0 | 4 | 30 | 100% | 60% | 75.0% |
| 순차공개 가격책정 | 2 | 8 | 0 | 2 | 30 | 100% | 80% | 88.9% |
| 순차공개 가격책정 | 3 | 10 | 0 | 0 | 30 | 100% | 100% | 100% |

정확 일치는 버전 1 **31/40**, 버전 2 **36/40**, 버전 3 **40/40**이었다. 버전 3의 단계 도달은 **120/120**, 미검사율은 **0%**, 평균 실행 시간은 설치된 Chrome에서 사례당 **0.33초**였다. 실행 시간은 브라우저 기동 이후부터 측정했다. 평가 스크립트는 이제 각 사례를 연속으로 두 번 실행해 단계·관측값·발견 결과의 반복 일치율도 함께 계산하고, 하나라도 불일치하면 평가를 실패시킨다.

2026-11-14 이후 실행 결과는 위 최신 기준을 사용한다. 과거 버전별 표는 규칙 개선 이력을 설명하기 위한 참고 자료이며, 출시 판정에는 사용하지 않는다.

버전 2는 유료 라디오·셀렉트·스위치의 초기 상태와 무료·선택 비용에서 필수 유료 비용으로의 전환을 검출했다. 버전 3은 데모 금액 속성이 없을 때도 명확한 유료 포장·보증 옵션과 필수 처리비·포장비 등 일부 한국어 문구를 인식한다.

추가 문구 변형과 정상 대조군 **29/29건**이 기대 결과와 일치했다. 사이즈에 따른 가격 차이, 조건부 비용, 예시 금액, 이미 공개된 비용, 같은 화면의 중복 표기, 긴급성·희소성 문구 조합과 공정위 가이드라인 16개 규칙 전체의 대표 문구를 포함했다. 기존 40건은 핵심 규칙 평가에 사용했고 확장 29건은 문구 변형과 전체 유형 신호 연결을 확인하기 위해 작성했다. 실제 쇼핑몰의 도달률과 탐지 성능은 운영자가 승인한 테스트몰에서 별도로 검증해야 한다.

## 재현

```sh
npm run evaluate
npm run evaluate -- --text-validation
# 또는 PLAYWRIGHT_CHANNEL=chrome npm run evaluate
npm run evaluate -- --text-validation
```

`scan-results/evaluation/summary.json`에 사례별 기대 결과, 관측 결과, 도달 단계, 반복 일치 여부와 소요 시간이 저장된다. 추가 사례의 결과는 `scan-results/text-validation/summary.json`에 기록된다. 각 사례 폴더의 `run-1`·`run-2` PNG와 JSON에서 반복 실행 증거를 확인할 수 있다.

## AI 정밀 분석 평가

AI는 기본 진단을 대체하지 않고, 기본 보고서가 남긴 미검증·검토 후보와 제한된 증거만 별도 분석한다. `npm run ai:evaluate`는 `datasets/ai-review.jsonl`의 운영자 라벨과 AI 예측을 비교해 정확도, 라벨별 정밀도·재현율, 미판정률, 예상 비용, 평균 지연시간을 계산한다. 라벨 데이터가 없으면 결과는 미판정이며 100%로 간주하지 않는다. 실제 운영 연결 전에는 쇼핑몰별 운영자 라벨을 축적한 뒤 고정 평가셋으로 모델·프롬프트·비용을 비교한다.
