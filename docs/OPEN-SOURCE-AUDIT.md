# 바로미 오픈소스 사용·라이선스 감사

바로미는 특정 쇼핑몰 플랫폼 SDK에 종속되지 않고, 브라우저 표준과 공개 웹 문서에서 공통 신호를 수집한다. 오픈소스도 검증된 구성요소만 사용하며, 특정 테스트몰의 코드·선택자·도메인을 제품 코드에 포함하지 않는다.

| 패키지 | 용도 | 라이선스 | 상용 사용 검토 |
| --- | --- | --- | --- |
| Next.js | 웹 애플리케이션/API | MIT | 허용. 고지 파일 유지 |
| React / React DOM | UI | MIT | 허용. 고지 파일 유지 |
| Playwright / @playwright/test | 격리 브라우저 탐색·검증 | Apache-2.0 | 허용. NOTICE·저작권 고지 유지 |
| Prisma / @prisma/client | 작업·결과 저장 계층 | Apache-2.0 | 허용. NOTICE·저작권 고지 유지 |
| better-sqlite3 | SQLite 드라이버 | MIT | 허용. 고지 파일 유지 |

라이선스 값은 설치된 패키지의 `package.json`에서 현재 버전을 확인했다. 배포 전 lockfile을 고정하고 의존성 변경마다 다시 확인한다. GPL/AGPL·네트워크 제한·비상업 조건이 있는 패키지는 별도 검토 없이는 추가하지 않는다.

## 적용 원칙

1. 정확도 기능은 먼저 기존 Playwright·DOM·네트워크 증거 계층으로 구현한다.
2. 외부 패키지는 유지보수 상태, 라이선스, 브라우저 격리와 개인정보 영향을 함께 검토한다.
3. 오픈소스는 판정을 대신하지 않는다. 규칙 버전, 관측값, 증거 ID는 바로미가 보존한다.
4. 실제 쇼핑몰 데이터·쿠키·결제정보를 외부 서비스로 전송하는 패키지는 사용하지 않는다.
5. 새 패키지는 최소 권한·동일 출처 제한·최종 주문 미실행 원칙을 통과해야 한다.

## 재검토 시점

- `package.json` 또는 lockfile 변경 시
- 브라우저 자동화·스크린샷·OCR·LLM 패키지를 추가할 때
- 상용 배포 번들을 만들기 직전

## 2026-11-13 검증 결과

- `npm audit --omit=dev --audit-level=high`: 알려진 높은 수준 이상 취약점 0건
- `npm audit --audit-level=high`: 개발 의존성 포함 높은 수준 이상 취약점 0건

이 결과는 현재 lockfile과 설치 상태에 대한 스냅샷이다. 의존성 업데이트 후 다시 실행해야 한다.
